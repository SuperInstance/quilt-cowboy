The 4 applications

1. Live Canon — papers as cells, reading as navigation

Reads the AI-Writings canon (1700+ papers) as a navigable cell fabric. Each paper = 1 cell. Each citation = 1 edge. Each F-number = a lineage trail.

5 novel operations:

NAVIGATE CONFLUENCE LINEAGE GHOST TICK

Demo: canon.lineage(115) returns F116 → F117 → F118 → F119, the polyformalism cascade from the first VHDL paper.

2. Doc Compounder — read a doc, snap to canon, find compounds

Decomposes any document (README, paper, blog post) into a 16-dial cell, then snaps it to the canon by shape. Returns:

  • Shape neighbors (k=3 most similar canon papers)
  • Conflicts (papers with overlapping F-numbers but different focus)
  • Ghost cites (canon papers this doc should cite)
  • Compounds (3+ papers that together cover the doc's F-numbers)

Use case: "I just wrote a doc — what does the canon say is related?" becomes a single function call.

3. Session Memory — turn a working session into a fabric

Each tool call in a session = 1 cell (dials = tool, args_hash, result_hash). Sequence edges auto-connect cells. Context edges connect cells that share tokens. The session serializes to a portable .quf file.

Operations: add, tick, save, load, query, similarity.

Use case: "I worked on something like this 3 months ago, what did I do?" becomes a single cell-fabric query.

4. Cell Merger — merge two fabrics into a synthesis

Given two QUF fabrics, computes the join fabric (cells in union, dials averaged for cells in intersection, edges from both). Also computes:

  • join_score(qf_a, qf_b) — similarity (cosine of dial vectors)
  • conflict_score(qf_a, qf_b) — 1 - similarity
  • ghost_cell(qf_a, qf_b) — positions of significant disagreement

Use case: "merge my chemistry notes with my music theory notes" → the synthesis fabric is the cell-level join.

The 5 insights from the ideator (Seed-2.0-mini)

  1. Papers as cells: a paper's purpose emerges from how it connects to others.
  2. Dial-vectors: measure directional citation impact, not just count.
  3. BFS through citations: traverse with intent — depth vs breadth first.
  4. Ghost papers: shape-similarity tells you whether a paper should exist.
  5. Tick: the canon is a living system that re-balances on new input.
